# Last Ferry · Dead City C 版

從專案根目錄執行 `node c/preview.mjs`，開啟 [本機試玩](http://127.0.0.1:4340/c/)。開始時有 10,000 試玩點數，下注額可調。驗證規則使用 `node --test c/verify.mjs`。

- 三次選路後迎戰守門人。六格彈巢五發起手，保守路先補一發並獲得一枚封條，衝鋒路以原彈量射擊並獲得三枚封條。都在命中後扣去該槍的一發。守門人前至少有五發。
- 空膛直接敗北。成功登船後在未封的箱子中按權重抽一箱。每枚封條排除一個最低倍數箱，普通箱各重 100，50× 黑盒重 2。實領等於箱子倍數乘下注額。
- 三個二選一決策共有八條路線。全保守通關率 83.33%，全衝鋒通關率 23.15%。精確計算的路線 RTP 介於 78.70% 與 135.54%。

六張背景以內建 ImageGen 製作，分別是風雨中的渡輪與閘門、左右雙路的水閘口、貨櫃場雙路、堤岸與登船坡道、港區遭遇走道，以及末班船貨艙。角色、武器、箱體和聲音沿用專案素材，C 版在本目錄有自己的副本。
