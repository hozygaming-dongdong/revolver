# Dead City · Bounty Run

B 分支的直式 Demo。從儲存庫根目錄執行 `node b/preview.mjs`，開啟 <http://127.0.0.1:4320/b/>。只使用本機試玩點數。驗證規則可執行 `node --test b/verify.mjs`。

設計驗收依照 [B 版設計鐵律](AGENTS.md)。選路時以街區內的入口命名與定位，印記的數量代表 X，終局獎格以物資圖示和倍率呈現。

- 前四關固定出保守和衝鋒。有符合條件的事件時，以 30% 機率加入第三條路。賞金彈巢固定 12 格，每一枚 X 把當下最低獎格換成重轉格，全局最多 9 枚。
- 六發起步。保守在開槍前補一發，前三關可補至六發，第四關可補至五發。第一關保守可帶六發離開，後續保守最多帶五發。白色保守保留進場彈量，藍色與橘色比進場多帶兩發，只有橘色給 1 枚 X。第二、三關之中只有一次藍色或橘色保守。
- 衝鋒用手上彈量開槍，命中後扣一發，白、藍、橘分別給 3、4、5 枚 X，牌面會顯示全局上限裁切後的數量。藍色或橘色衝鋒最多出一次，火力剩四發或以下時稀有衝鋒為橘色，電台也可指定橘色衝鋒。
- 彈藥箱命中後補到五發。警衛室的兩個標記實彈格給 4 枚 X，其餘實彈格給 1 枚。電台給 2 枚 X，並把尚未出現的稀有路線提前到下一關並升為橘色。警衛室與電台命中後保留進場彈量。
- 五關的遭遇由 WebGL 做第一人稱進場，路面、障礙與各關殭屍各有深度。維修巷用近景貨箱遮住感染者，路障則能從遠處看見敵人。若瀏覽器不提供 WebGL，沿用靜態遭遇畫面的進場。
- 補彈會先展示開巢，再照亮新入彈的那一格。指針停在實彈時有槍口光、後座與殭屍倒下；空膛則只發出乾響，殭屍上前。
- 第五關一槍打 Boss，開槍前至少補至四發。每次射擊等機率從六格選一格，任一空膛結束本局。Boss 命中才開放賞金彈巢。普通高獎是 2.25× 和 4.5×。一般獎格和 X 各重 100，50× 黑盒重 2。停在 X 使黑盒增加 2× 並自動重轉，原 X 保留，倍率無上限；停在獎格才派彩一次。
- 五種透明敵人、裝彈前景與兩種表面材質是 B 版新素材。六格彈巢與既有場景物件唯讀引用 A 的資源，音效由 B 版合成。
