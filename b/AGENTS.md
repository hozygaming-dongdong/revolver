# B 版設計鐵律

**拿掉投注與派彩，遊戲仍要是一場值得玩完、有臨場感的逃生冒險。** 玩家應能從場景看出自己在哪、要往哪裡走、冒著什麼危險。找路、遭遇、看彈巢停格和取得物資，本身就要有足夠的張力和回饋。

- **路線先有場景，再有規則。** 用可辨識的入口、照明、路標與障礙，讓玩家感覺自己在選一條路。將路線類型、風險與回報放在入口附近，容易比較。
- **物件和動作優先用圖示表達。** X 用一致的可收集物件呈現，終局獎格用可辨識的物資圖示。每個圖示在路口、收集回饋與結算間都要一致。
- **玩家隨時知道目標、代價和結果。** 選路前看得到命中率、命中後的回報與彈巢。抽獎時看得到仍在盤上的獎、各格機會及實領金額。六格戰鬥彈巢和終局獎盤都以固定指針的停格為焦點。
- **手機直式單屏完成。** 採用英文介面。路口、射擊與獎盤的核心操作在 360×640 和 390×844 都應完整可見，不用上下滑動。

評審時先試著遮住金額，只看環境、路線、彈巢與遭遇演出。若玩家說不出自己為什麼要前進、想走哪個入口，或對停格缺乏期待，優先修畫面和互動。
