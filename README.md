# CHAMBER · UI Prototype

這是一個從零重建的手機直版 UI Prototype，暫時不沿用舊版遊戲 UI、HUD、彈巢或流程。這一輪只驗證視覺語言與五個核心情境：

1. 開始畫面
2. 選門畫面
3. 目標揭露畫面
4. 彈巢與開槍畫面
5. 獎勵抽選畫面

## 鐵律

- 只以手機直版作為標準。
- 核心操作必須在單一可視畫面內完成，不依賴上下滑動。
- 玩家先看懂畫面，再讀必要文字。
- UI Prototype 通過前，不接回完整遊戲規則。

## 試玩

直接開啟 `index.html`，或執行 `node preview.mjs` 後開啟本機預覽。

目前按鈕只展示畫面流程，不代表最終遊戲數值與規則。
