# REVOLVER · 封鎖區

手機直式第一人稱左輪博弈 Demo，使用瀏覽器本機的試玩點數。

- 開局押分，先走五輪備戰。每輪從五種獎勵中抽出兩扇門，彈巢低於兩發時必出補給門。
- 開槍前隨機轉彈巢。備戰命中可轉獎勵輪盤，空炮結束本局。普通彈超出彈巢容量時存入口袋，特殊彈留到 Boss 戰。
- Boss 有三點生命，三次開槍機會用完後反擊。每槍前可配置多顆彈藥，最多裝五發。爆擊彈造成兩點傷害，冰凍彈造成一點並延後反擊，賞金彈造成一點並抽取賞金加成。同類爆擊或冰凍彈裝三發可強化該彈命中效果。
- 打倒 Boss 後抽基礎倍率，乘上累計賞金加成，派彩上限為押分的十倍。

## 鐵律

- 以手機直式為標準，主要操作在單一可視畫面完成，不需捲動。
- 玩家隨時知道在追逐什麼，每一步都有明確目標與結果。
- HUD 維持固定規格，場景優先用圖像引導。

執行 `node preview.mjs` 開啟本機預覽。規則檢查使用 `node verify.mjs`。
