# REVOLVER · 左輪追獵

手機直向的八回合左輪追獵 DEMO。玩家每回合先選一扇門，再看門後目標並開槍；實彈成功，空炮死亡。撐過第 8 回合後，進行一次最高 10X 的最終抽獎。

## 鐵律

- **手機直版優先**：遊戲只以手機直向畫面作為標準，不支援橫向遊玩。
- **單一視窗完整可玩**：核心操作、彈巢與 `FIRE` 必須在同一個可視畫面內完整呈現，不得依賴上下滑動。
- **先驗證最小高度**：任何版面調整都要以窄螢幕與手機瀏覽器動態工具列的可視高度檢查，確認沒有裁切、水平溢出或被底部瀏覽器列遮住。
- **視覺先於長文**：玩家應先透過門、目標、彈巢與結果看懂下一步，文字只做必要補充。

## 試玩與驗證

- 直接用瀏覽器開啟 `index.html`。
- 或執行 `node preview.mjs`，再開啟 `http://127.0.0.1:4197/Revolver/`。
- 執行 `node verify.mjs` 可驗證六格彈巢、補彈抽選、最終倍率抽選與 UP 封頂。

## 初版規則

| 項目 | 設定 |
| --- | --- |
| 回合 | 共 8 回合，前 5 回合可補彈，後 3 回合不補彈 |
| 彈巢 | 六格，開局 6 發；每次開槍依目前彈藥比例隨機滾動 |
| 補彈 | 成功擊殺補彈殭屍後抽 `+0`、`+1`、`+2`，權重為 5%、55%、40%，上限 6 發 |
| 獎金 UP | 成功擊殺獎金殭屍後累積 1 層 UP |
| 最終抽獎 | `1.2X`、`1.5X`、`2X`、`3X`、`10X`，權重為 40%、30%、16%、10%、4% |
| UP 效果 | 最終抽到的倍率依 UP 層數往上提升，最高封頂 `10X` |
| 基礎獎金 | `$100` |

## 設計宗旨

玩家要知道自己在追逐什麼，每一步的目標與結果都要清楚。初版優先驗證目標選擇、開槍結果、彈藥壓力與第 8 回合最終抽獎，不先追求完整美術或複雜技能。
